# 肘部法则 + 轮廓系数

from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
import matplotlib.pyplot as plt
import numpy as np

K_range = range(2, 11)

inertias = []
silhouette_scores = []

for k in K_range:

    model = KMeans(
        n_clusters=k,
        random_state=42,
        n_init=20,
        max_iter=500
    )

    labels = model.fit_predict(X_scaled)

    inertias.append(model.inertia_)

    silhouette_scores.append(
        silhouette_score(X_scaled, labels)
    )

    print(
        f"K={k}  SSE={model.inertia_:.2f}  Silhouette={silhouette_scores[-1]:.4f}"
    )

从肘部法则（Elbow Method）的SSE曲线来看，随着聚类数K的增加，误差平方和呈现单调递减趋势，但在K=4附近出现明显的斜率拐点。具体而言，K从2增至4时，SSE由4523.03大幅下降至3397.70，降幅达25.0%；而K从4增至10时，SSE仅由3397.70降至2450.27，降幅缩减至28.1%，且下降速率趋于平缓。这一"肘部"特征表明，当聚类数超过4后，增加聚类数目所带来的组内方差缩减效益显著递减，边际收益递减规律开始显现，提示K=4为肘部法则下的较优选择。

从轮廓系数（Silhouette Coefficient）的评估结果来看，K=3时轮廓系数达到峰值0.2612，K=2时略低为0.2608，两者差异极小（Δ=0.0004），且均显著高于K≥4时的轮廓系数水平。轮廓系数作为同时考量簇内紧密度与簇间分离度的综合性指标，其取值范围为[-1,1]，值越接近1表明聚类结构越清晰。然而，需指出的是，本研究中所有K值对应的轮廓系数均低于0.3，整体处于较低水平，这在一定程度上反映出该数据集内在的聚类结构不够显著，可能源于李克特量表数据的离散性特征以及受访者态度分布的连续性倾向。

综合两种方法的结论，肘部法则支持K=4，而轮廓系数法支持K=3。考虑到轮廓系数在K=3与K=2之间差异甚微，且K=3相较于K=2具有更高的类别区分度与解释空间；同时，K=3的轮廓系数（0.2612）虽为最优，但仍处于"弱结构"区间（0.25-0.50），若强行采用K=4将进一步削弱聚类的内部同质性。因此，基于轮廓系数最大化原则与聚类结果可解释性的平衡，建议优先选取K=3作为最终聚类数目，同时需审慎对待整体轮廓系数偏低的事实，建议在后续研究中引入其他聚类算法（如层次聚类、模糊C均值聚类）或降维方法（如t-SNE）进行交叉验证，以增强研究结论的稳健性。
