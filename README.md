# 多源数据分析下 Z 世代线下演唱会支付意愿预测与体验优化研究

> 基于 550 份问卷 + 2006 条社交媒体评论，融合 K-means 聚类、随机森林回归、LDA 主题模型与 TOPSIS 评价方法，构建从"消费者画像 → 意愿预测 → 舆情诊断 → 方案择优"的完整数据分析链路。

---

## 项目背景

Z 世代（1995—2009 年出生）已成为线下演唱会消费主力人群，但其消费行为中"高情感需求"与"低经济基础"的结构性矛盾日益凸显。现有研究多聚焦"为何消费"的动机阐释，对"如何预测消费"和"如何优化运营"两类决策导向问题关注不足。

本研究构建"多源数据协同—消费者画像—消费意愿预测—舆情分析—运营优化"研究框架，实现从"单源描述"向"多源协同"的范式转换。

## 分析模块一：消费者画像构建（K-means 聚类）

### 聚类指标

基于 11 个 Likert 量表题项归入 4 个主观指标，结合观演频率和单次消费金额，形成 6 个核心聚类指标：

| 指标 | 来源 |
|:---|:---|
| 艺人忠诚度 | Q1 |
| 消费动机 | Q2-Q4 | 
| 价格敏感度 | Q5-Q8 | 
| 体验诉求 | Q9-Q11 | 
| 单次消费金额 | 问卷数据 | 
| 观演频率 | 问卷数据 |

### 最优聚类数确定

**肘部法则**（SSE 降幅拐点）与**轮廓系数法**（簇内紧密度+簇间分离度）综合判断：

| 肘部法则 | 轮廓系数 |
|:---:|:---:|
| ![肘部法则](output/images/fig03_elbow_method.png) | ![轮廓系数](output/images/fig04_silhouette_coefficient.png) |

k=3 时轮廓系数达峰值 0.2612，且簇间边界更清晰；k=4 虽小幅提升簇内同质性但削弱簇间分离度。**最终选取 k=3**。

### 聚类结果

![K-means聚类散点图](output/images/fig05_kmeans_pca_scatter.png)

PCA 降维至二维：PC1 解释 47.3%，PC2 解释 24.1%，累计 71.4%。

![聚类中心热力图和雷达图](output/images/fig06_cluster_heatmap_radar.png)

| 消费者类型 | 占比 | 核心特征 | 运营方向 |
|:---|---:|:---|:---|
| **狂热核心型** | 53.8% | 高忠诚(0.49)、高消费(0.59)、高频次(0.51)、低价格敏感(-0.52) | 会员体系、粉丝权益、衍生品 |
| **边缘观望型** | 24.5% | 全维度低于均值(-0.24~-1.32)、低黏性 | 市场推广、社交媒体传播 |
| **价格敏感型** | 21.6% | 价格敏感度极高(1.04)、低消费金额(-1.20) | 票价分级、信息透明、差异化定价 |

### 部分依赖图（PDP）——非线性效应分析

![部分依赖图](output/images/fig11_partial_dependence.png)

| 变量 | 效应方向 | 关键发现 |
|:---|:---|:---|
| 座位影响价值 | 正向单调递增 | 1→5 分，预测值 2.50→4.40，无饱和效应 |
| 购票选位满意度 | 正向递增（高分加速） | 4-5 分区间提升幅度更明显 |
| 定价合理性 | **负向** | 认为定价不合理的群体反而支付意愿更高（约4.00 vs 3.50） |
| 加强秩序管控 | **倒 U 型** | 中等诉求(3-4分)峰值约3.80，极端值反而下降 |

### 核心洞察

> **"双因素主导"层级结构**：座位影响价值 + 购票选位满意度累计贡献 69.19%，构成支付意愿直接决定层；观演动机是深层情感基础（因子重要性最高但特征重要性低）；秩序管理是"门槛条件"而非"吸引因素"。

## 分析模块四：运营优化方案评价（TOPSIS）

基于画像、预测与舆情分析结果，设计三类候选方案：

| 方案 | 内容 |
|:---|:---|
| 方案A | 票务公平优化：完善实名购票机制，加强黄牛治理 |
| 方案B | 观演体验优化：优化座位展示、现场互动、秩序管理 |
| 方案C | **综合运营优化：融合票务优化+体验提升+消费者分层运营** |

**评价指标与权重**：消费者满意度提升能力(0.35) + 支付意愿促进能力(0.30) + 问题覆盖能力(0.25) + 实施可行性(0.10)

### TOPSIS 评价结果

| 方案 | D⁺（距正理想解） | D⁻（距负理想解） | 贴近度 Ci | 排序 |
|:---|---:|---:|---:|:---:|
| **方案C 综合运营优化** | 0.026574 | 0.071008 | **0.727674** | **1** |
| 方案B 观演体验优化 | 0.026419 | 0.062224 | 0.701964 | 2 |
| 方案A 票务公平优化 | 0.080884 | 0.014359 | 0.150764 | 3 |

> **结论**：综合运营优化方案（方案C）贴近度最高，多维度协同推进策略具有叠加效应。

## 研究局限与效度说明

社交媒体爬虫数据无法按年龄精确筛选，可能包含非 Z 世代用户评论。
本文的应对策略：
- 角色分工：文本数据仅用于「市场舆情扫描」，不作「Z 世代态度」的直接证据；
- 偏差方向：当前主流平台（小红书/微博）用户结构整体偏年轻，偏差方向向 Z 世代倾斜；
- 三角验证：问卷与文本两独立来源均指向「座位价值错配 / 票务公平」核心痛点，跨源稳健；

## 核心结论

1. **消费者画像**：Z 世代演唱会消费者可划分为三类——狂热核心型(53.8%)、边缘观望型(24.5%)、价格敏感型(21.6%)，Bootstrap 检验 Jaccard 均值 0.8746 证实结构稳健

2. **支付意愿驱动**："座位影响价值"与"购票选位满意度"累计贡献 69.19%，构成"双因素"核心驱动；观演动机是情感基础而非直接驱动；秩序管理是"门槛条件"

3. **舆情痛点**：座位体验、票务公平、主办方管理为三大核心痛点，"座位安排与实名制度"主题风险指数最高(0.2377)

4. **方案择优**：综合运营优化方案 TOPSIS 贴近度最高(Ci=0.7277)，多维度协同优于单一优化
